## 4. 波动规律说明

- **磁盘受限场景（B4，50 线程）**：吞吐 41~70 万条/秒（±27%），主要受内核页缓存回写时机与 VM 磁盘状态影响。
- **纯 CPU 场景（B1/B6/B5 全过滤）**：单次波动可达 ±40%，vCPU 抢占与宿主负载是主因。
- **复测方法**：`./bench_median.sh`（仓库内置，默认 5 次 × 场景 1/2/4/6，自动输出中位数与范围）。
